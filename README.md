## About Me

Full-spectrum engineer — I write production web applications, design embedded firmware, and build autonomous robotic systems. My work spans from **JavaScript front-ends and PHP back-ends** to **C/C++ firmware on bare-metal microcontrollers** and **Python-driven ROS2 robotic stacks**.

I focus on building **practical, reliable systems** end-to-end: from a clean UI in the browser all the way down to sensor hardware talking over RF.
